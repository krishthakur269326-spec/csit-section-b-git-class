1. Download Git
2. Go to github and make a repository 
3. open our file 
4. git init .
5. git remote add origin https://github.com/krishthakur269326-spec/csit-section-b-git-class.git
6. git add .
7. git commit -m "changes name"
8. git push --set-upstream origin main
9. git branch > to look all the branches in git
10. git checkout -b branchName > is used to make another branch and switch to that branch
11. git checkout branchName is used to switch branches
